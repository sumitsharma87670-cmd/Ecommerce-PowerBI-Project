E-Commerce Sales Analysis Dashboard

Project Overview

This project focuses on analysing e-commerce sales data and building an interactive dashboard using Power BI.

Tools Used

- Power BI
- MySQL

Dashboard Features

- KPI Cards: Total Revenue, Total Orders, Total Customers and Average Order Value
- Monthly Revenue Trend
- Revenue by City
- Revenue by Category
- Orders by Status
- Top 5 Products by Revenue
- Interactive slicers for City and Order Status

Data Model

The project uses four related tables:

- Customers
- Orders
- Order_Details
- Products

Files Included

- "Ecommerce_Sales_Analysis.pbix" – Power BI dashboard file
- "Dashboard.png" – Dashboard screenshot
- "Model_View.png" – Data model and relationships screenshot

Key Learning

This project helped me practise data modelling, creating DAX measures, building interactive visualisations and analysing business performance using Power BI.
